# Kubernetes

End-to-end Kubernetes tutorial notebook covering cluster setup, deployments, services, and production patterns.

## Contents

- **kubernetes-end-to-end.ipynb**: Complete Kubernetes learning guide with practical examples and best practices

## Getting Started

1. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the notebook:
   ```bash
   jupyter notebook kubernetes-end-to-end.ipynb
   ```

## Prerequisites

- Kubernetes cluster (local or cloud)
- kubectl CLI
- Docker
- Python 3.8+
